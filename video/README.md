# PackSense product demo

An editable 61.5-second Remotion film made from real PackSense browser recordings, animated decision diagrams, narration, and an original ambient score. The film shows a fresh asparagus evaluation against the deployed backend. Its journey values are illustrative and its actual result is **Needs evidence** with eight open checks. The film does not claim a deployed material or shelf life predictor.

## Edit and render

```sh
cd video
npm ci
npm run studio
npm run render
```

The composition is `PackSenseProductDemo` (1920 × 1080, 30 fps). Source scenes and timing are in [`src/video.tsx`](src/video.tsx), narration lines in [`narration.json`](narration.json), live footage in `public/clips/`, selected stills in `public/screens/`, and audio in `public/audio/`. The full size master lands in `out/`, which is ignored by Git. The smaller website export lives in `web/media/`.

The voice tracks are checked in so rendering does not depend on a speech service. To regenerate narration with the same voice, install `edge-tts` and run `python scripts/make_audio.py`. The score is generated by that script from original synthesized tones. To refresh the live footage with Playwright and Chrome, run `node scripts/record-live.mjs food`, then `node scripts/record-live.mjs fresh` and `node scripts/record-live.mjs fresh-evidence`. Verify any revised claim against the current backend contract and `web/demo/report.json` before publishing.

The public website version is H.264/AAC at 1280 × 720, with a poster and WebVTT captions for the native video player.
